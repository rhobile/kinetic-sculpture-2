
# Rhobile | Gallery Management & Security Guide

## 🚀 Recommended: Direct GitHub Deployment
Ensure you are pushing to the correct repository: **rhobile/kinetic-sculpture-2**.

1.  **Wait for "All changes published"**: Look at the status bar at the very bottom.
2.  **Publish to Studio**: You MUST click the **PUBLISH** button in the top toolbar to apply changes to your files.
3.  **Push to GitHub**: Click the **Cloud with Up Arrow** icon to send changes to your live site.
4.  **Commit Message**: When the message box appears, **type your own comment** summarizing your changes (e.g., "Wrap titles and fix spacing"). If it shows a previous request, just clear it and type your own.

## 🔐 Troubleshooting Repository Mismatch
If you see a different repository name (like `studio-2may`) in the push dialog:
- Look at the **top header toolbar** next to the project name.
- Click the **GitHub icon** or the **Settings (cog)**.
- Disconnect the current repository and search for **rhobile/kinetic-sculpture-2** to reconnect it.

## 📂 Media Folders
- **`ks-images/`**: Upload all `.jpg`, `.jpeg`, and `.png` thumbnail images here.
- **`ks-videos/`**: Upload all `.mp4` video files here.
- The gallery is "Storage-first": upload a thumbnail to `ks-images/` to make a sculpture appear instantly.

## 🔐 Hidden Admin Doorway
Visit `https://rhobile.com/manage` directly to log in as **rhobile@gmail.com**. Once logged in, the "Unified Management" link will appear in your sidebar.

## 🛠️ Mobile Spacing & Typography
- **Spacing**: Vertical gaps between videos and titles are tightened for an elegant mobile portrait look.
- **Titles**: Optimized at **9pt/11pt** uppercase. They are now configured to **wrap to a second line** instead of being cut off on narrow screens.
