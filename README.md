# Rhobile | Gallery Management & Security Guide

## 🚀 Recommended: Direct GitHub Deployment
Ensure you are pushing to the correct repository: **rhobile/kinetic-sculpture-2**.

1.  **Wait for "All changes published"**: Look at the status bar at the very bottom. 
2.  **Publish to Studio**: Click the **PUBLISH** button in the top toolbar to apply AI changes to your workspace.
3.  **Push to GitHub**: Click the **Cloud with Up Arrow** icon. 

### ⚠️ Troubleshooting Repository Mismatch
If the push is failing or going to `studio-2may`:
- Look at the **Top Header** of the Firebase Studio screen.
- Find the **Cloud icon** (with the up arrow) or the **GitHub icon**.
- Clicking this icon usually opens the deployment panel.
- Look for **"Settings"** or a **"Connect Repository"** option within that panel.
- Disconnect and reconnect to: `rhobile/kinetic-sculpture-2`.

## 📦 Alternative: Manual Download (ZIP)
1.  **Locate the Button**: The **Zip and Download** button is in the **TOP TOOLBAR** header (cloud with arrow pointing **DOWN**).
2.  **Download Entire Zip**: You must use the full zip to overwrite your local project folder. Do not just zip the `src` folder.

## 🔐 Hidden Admin Doorway
Visit `https://rhobile.com/manage` directly to log in as **rhobile@gmail.com**. Once logged in, a "Manage Dashboard" link will appear in your sidebar.
